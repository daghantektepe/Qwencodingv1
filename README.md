# OpenScriv

OpenScriv is a local-first desktop writing studio for long-form projects. It is built with Electron, React, TypeScript, and Vite.

## Commands

- `npm install`
- `npm run build`
- `npm test`
- `npm run electron:dev`

## Current MVP

- Binder-style document tree
- Focused editor
- Inspector metadata panel
- Live word count and project target progress
- Local autosave model ready for Electron IPC persistence
